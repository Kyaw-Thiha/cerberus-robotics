# Pinned additive packages installed into Isaac Sim's bundled Python
# interpreter (via _isaac_sim/python.sh -m pip install -r) on top of
# whatever Isaac Sim/Isaac Lab already ships. This is the reproducibility
# mechanism for that additive layer -- pixi.lock plays the equivalent role
# for the local dev env, but pixi doesn't fit here (see docs/artifact_storage.md's
# note: pixi owns/creates its own interpreter, it doesn't attach packages to
# an externally-provided one like Isaac Sim's). Versions verified installable
# via `pip index versions <pkg>` at the time each was added.
#
# wandb -- default experiment logger for policy/locomotion/train.py.
# imageio[ffmpeg] -- direct frame-writing for core/video_capture.py's
#   multi-condition capture loop (play_terrain_showcase.py,
#   eval/push_recovery_showcase.py) -- not RecordVideo-based, see that
#   module's docstring for why.
# pyzmq/msgpack -- IPC transport out of this interpreter, for
#   slam/slam/ground_truth/sim_ground_truth_loop.py to hand ground-truth
#   pose + raw sensor data to the separate rclpy-side process (pixi's
#   sim-ros2 env, a different Python entirely -- see that env's pixi.toml
#   comment for why rclpy can't live in this interpreter directly).
